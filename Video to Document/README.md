# Video to Document

`Video to Document` 是一个把视频或音频转换为 Markdown 文档的 Codex skill。输出文档必须包含：

- `原文`：视频或音频的原始转写文本，可包含时间戳。
- `概述`：对视频主题、结构、主要内容和上下文的整体说明。
- `总结`：对关键结论、要点、行动项或最终观点的精炼总结。

```text

```
